# Учебный пульт: Unreal + GPT-Live + MCP

Нативное Mac-приложение с 3D-пультом и голосовым помощником. Пользователь управляет мышью, Unreal проверяет четыре действия, GPT-Live объясняет текущий шаг и подсвечивает нужный элемент через настоящий MCP Streamable HTTP с подтверждением сцены.

## Упражнение

1. Зажать круглую ручку и повернуть в любую сторону хотя бы на 5°.
2. Перетащить горизонтальный переключатель вправо и отпустить.
3. Набрать **773** на клавиатуре пульта и нажать **Enter**. «Очистить» сбрасывает ввод.
4. Нажать на рычажный тумблер, изменив его положение.

Все элементы доступны постоянно. Действия заранее не засчитываются: если переключатель уже справа, на втором шаге верните его влево и снова вправо. При входе в третий шаг поле кода очищается. Выполненные шаги сохраняются при дальнейших манипуляциях. «Начать заново» сбрасывает упражнение; завершение разговора сохраняет прогресс до выхода из приложения.

Приложение запускается в обычном окне 1280×800. На проверенном Mac полноэкранный режим терял попадание мыши в интерфейс; для MVP используйте оконный режим. Для диагностики маршрута нажатий предусмотрен параметр `-LabInputDebug`.

Нажмите **«Начать разговор»**, разрешите микрофон и используйте наушники. Помощник произнесёт общее вступление и будет ждать запроса. Переходы между этапами не озвучиваются автоматически. Можно спросить «Что дальше?» или «Что я уже сделал?». Положение приборов меняет человек; агент не имеет инструмента для выполнения действий за пользователя.

## Сборка и запуск

Нужны macOS Apple Silicon, Node.js 22.6+, Unreal Engine 5.8 и совместимый Xcode с Metal Toolchain. Проверенная базовая среда: UE 5.8.3, Xcode 26.1.1, Mac SDK 26.1, Apple M1. Совместимость других версий проверяйте по [требованиям Epic](https://dev.epicgames.com/documentation/unreal-engine/macos-development-requirements-for-unreal-engine).

```sh
npm ci
cp .env.example .env
# Задайте OPENAI_API_KEY локально в .env.
npm run package:mac
```

Пакет: `.runtime/package/Mac/FiveCubes.app`; ярлык на рабочем столе — **«Пять кубиков»** (историческое имя проекта). Пакет содержит Node.js 22.22.3 arm64 и сервер, запускаемый автоматически на свободном loopback-порту. Редактор и отдельный запуск сервера для готовой сборки не нужны. Подпись локальная ad-hoc, публичного установщика и notarization нет.

Путь к движку можно переопределить через `UE_ROOT`. При отсутствии Metal:

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -downloadComponent MetalToolchain
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun --kill-cache
```

Настройки: `~/Library/Application Support/FiveCubes/settings.json`, поле `env_file`. Первая сборка указывает на `.env` проекта; при переносе проекта обновите этот путь. Ключ не копируется в `.app`. Файлы сопряжения и журнал событий находятся в `~/Library/Application Support/FiveCubes/Sessions/<PID>/`. Сервер завершается при выходе из приложения.

Для разработки: `npm start` в одном терминале, `npm run unreal` — в другом. Соединение читается из `.runtime/connection.json` с правами 0600.

## Сценарий, подсветка и голос

Общее описание: `unreal/FiveCubes/Content/Lab/scenario.json`. Его читают Unreal и сервер; упаковщик включает файл в обе runtime-среды. Порядок, цели, ID, порог вращения и код берутся оттуда. Семантика четырёх действий проверяется C++-машиной состояния `PanelProgress.h`.

Цели: `panel.rotary`, `panel.slider`, `panel.keypad`, `panel.toggle`; отдельные клавиши — `panel.keypad.0`…`panel.keypad.9`, `panel.keypad.C` (очистить), `panel.keypad.E` (Enter). Подсветка мигает на самой ручке, ползунке, рычаге или выбранной клавише: 0,5 секунды яркого цвета и 0,5 секунды исходного. Новая команда начинает с яркой фазы; снятие сразу возвращает исходный материал. `panel.keypad` выделяет все клавиши. Отдельный каталог `unreal/FiveCubes/Content/Lab/targets.json` задаёт ID, названия и принадлежность элементам пульта независимо от сценария. MCP предоставляет `lab_get_state`, `lab_highlight(target_id, text)` и `lab_clear_highlight`. `allowed_targets` содержит весь каталог на любом этапе, включая завершённое упражнение. Успех возвращается только после ACK из Unreal.

Снимок содержит `session_id`, `scene_version`, `state_seq`, `stage`, `stages_total`, `stage_id`, `stage_goal`, `finished`, `completed`, `allowed_targets`, `instrument_state`; сервер добавляет `revision`. `instrument_state` включает угол ручки, положение горизонтального переключателя, состояние тумблера, введённые цифры и ошибку кода. Завершение: `stage=4`, `stage_id=complete`, `finished=true`, четыре выполненных шага.

`state_seq` упорядочивает снимки. Телеметрия не отменяет допустимые команды; смена этапа/сцены увеличивает revision и отменяет ожидающие устаревшие команды. Смена этапа сохраняет уже установленную подсветку. Сброс создаёт новый `scene_version`. Проверки цели, сцены и этапа выполняются и сервером, и Unreal.

Транспорт: нативный микрофон → PCM16 mono 24 kHz → `/voice` WebSocket → `gpt-live-1` → backend `gpt-6-sol` → MCP → `/scene` WebSocket → Unreal. Видео не передаётся. `OPENAI_BACKEND_MODEL` и `OPENAI_LIVE_MODEL` настраиваются через `.env`.

После `session.started` сервер озвучивает вступление. Подсветка при запуске выключена. Изменения этапов и показаний обновляют контекст молча, без MCP-вызовов и разрыва разговора. Устаревшие ожидающие подсказки отбрасываются. По просьбе «подскажи, что дальше» backend читает состояние и выделяет нужный элемент. По прямой просьбе может выделить любой элемент каталога независимо от этапа. Для ввода кода выбирается следующая цифра, Enter или очистка ошибочного ввода. Обычные вопросы подсветку не меняют. Новая цель заменяет предыдущую; просьба убрать, кнопка снятия, завершение разговора, сброс и отключение сцены очищают её.

`/voice` требует `hello` с `session_id` и локальным токеном. Затем принимает `voice.start`, `voice.stop`, `lab.command`; сервер отдаёт состояние, PCM, транскрипт и результаты. `voice.reset_output` очищает локальную очередь устаревшей речи при переходе. Прогресс упражнения не зависит от доступности голоса. При обрыве соединения разговор нужно запустить заново.

Один сервер обслуживает одну сцену и один голосовой контроллер. Ключ хранится на сервере; токен сопряжения не является API-ключом. Сервер слушает только loopback. Многопользовательский режим и сетевое развёртывание не реализованы.

## Проверки

```sh
npm run check
npm run test:scenario
npm run test:audio
```

Проверяются порядок действий, преждевременное управление, неверный код, повторный Enter, сброс, ограничения MCP, устаревшие команды, обновления телеметрии и голосовое сопровождение без перезапуска сессии. Тесты голоса используют подставного провайдера; настоящая сессия проверяется отдельно.

При запущенном сервере разработки и подключённом Unreal:

```sh
npm run smoke:mcp
npm run smoke:live
# Дополнительно: WAV PCM16 mono 24 kHz с просьбой подсветить текущий элемент.
npm run smoke:live -- /путь/voice-test.wav
```

`smoke:live` выполняет платные API-вызовы. Он проверяет инструмент и получение аудио; субъективное качество звучания проверяет человек. Проверка упаковки `scripts/verify-mac-bundle.py` контролирует ARM64-зависимости, cooked-пакет и подпись.

VR/OpenXR, шлем и измерение задержек на шлеме остаются за пределами этой версии. Git исключает ключи, runtime-файлы, журналы, зависимости, Unreal Engine и сборки.

Проверено 30 сентября 2026: 12 серверных тестов, C++-проверки сценария и аудио, сборка Mac. Реальный GPT-Live ранее проверен с тестовым адаптером; автоматическое сопровождение этапов с 1 октября убрано. MCP отдельно проверен на упакованном Unreal. Полное прохождение обычной мышью подтверждено пользователем в оконном режиме и состоянием Unreal: `finished=true`, ползунок `right`, код `773`, все четыре шага выполнены. Верхняя кнопка сброса и одиночное переключение рычага также проверены. Голосовое прохождение в упакованном приложении отдельно ещё не подтверждено.

Проверено 1 октября 2026 для подсветки по запросу: 12 серверных тестов и C++-тест сценария; 20 MCP-проверок на упакованном Unreal, включая все 16 целей на первом этапе и отклонение устаревшей команды. Настоящий GPT-Live произнёс вступление без вызовов инструментов; обновление этапа в тестовом адаптере не вызвало новой речи. Прямой текстовый запрос через настоящий GPT-Live/backend выделил `panel.keypad.3` в Unreal на первом этапе, получен ACK и визуально проверена именно клавиша 3. Это проверка голосового API с текстовым запросом, а не подтверждение ввода с физического микрофона.

Ручная голосовая приёмка этой сборки подтверждена пользователем 1 октября 2026: после вступления просьба «Подсвети клавишу три» выделила клавишу; поворот ручки перевёл упражнение на следующий этап и сохранил подсветку; просьба «Убери подсветку» сняла её.
